2 · Outline
Teak: spacing on centre.
Finds the deck and unrolls each panel at its true size — an angled panel keeps its real measurements. The pattern also works out which way the boat runs, and that is what every seam is later squared to. A new scan takes a few minutes, then it is cached.

3 · Auto-fit
Turns the scanned edge into clean lines and arcs, kept 1.5 mm inside the deck so a part is never cut oversize. Writes final_auto.dxf.

Ingest a drawn .3dm

Only if you drew the outline yourself in Rhino. Auto-fit does this for you.

The pieces and the sheets are worked out again after every change on their own, so Recalculate is only here for when you want to see it done again. Clear all seams asks first, and there is an Undo straight afterwards.

Let the computer try

Puts the seams where every piece fits a sheet and the least material is wasted, with the fewest joins it can. It searches for about a minute and a half and keeps the best it found — not a proof that nothing better exists. Your seams are saved first and there is an Undo; you can still move or remove any of them afterwards.

Cut files

One DXF per 40×80″ sheet, ready for VCarve, with the grain running along the boat.
Settings
Set these once. The defaults suit Reflex TruGrain on 40×80″ sheets.

Straightening

Long seams run with the boat and the teak lines, short ones square across it, so no piece comes out wedge shaped.
For a diagonal seam: if it is nearly along a console or hatch edge, put it on that edge. A seam straightened to the boat still slides sideways onto an edge that is already square.

Nesting

Leave the grain angle blank to use the boat direction the outline found. Typing one overrules it, and every seam is squared to that instead.
